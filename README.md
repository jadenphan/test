# 🇦🇺 澳洲华人工资记账软件 (Australia Salary Tracker)

一个专为澳洲华人设计的轻量级工资与工时记录 Web 应用。

无需注册、无需登录、无需安装 App，打开网页即可记录每日工时，并自动统计每周、每月的工作数据。

## ✨ 功能特点

* 📅 记录每日工作信息

  * 工作日期
  * 工作地点
  * 工作时长
  * 小时工资

* 📊 自动统计

  * 每周总工时
  * 每周总薪资
  * 每月总工时
  * 每月总薪资

* 📈 工时分布可视化

  * 周工时统计
  * 月工时统计

* 🔄 自定义考勤周期

  * 支持周一、周二、周三……周日作为每周起始日

* 📂 数据导出

  * 导出 Excel
  * 分享工资工时图片

* ⚡ 快捷录入

  * 最近使用的工作地点
  * 最近使用的工作时长

* 💾 本地数据存储

  * 所有数据保存在浏览器 LocalStorage
  * 无需账号
  * 不上传服务器
  * 保护个人隐私

## 🚀 技术栈

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage
* html2canvas
* SheetJS (xlsx)

## 📱 使用方式

直接打开网页即可使用。

由于数据存储在浏览器本地，建议使用固定浏览器访问，避免清除浏览器缓存导致数据丢失。
